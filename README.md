# 面试 Galgame

用视觉小说式对话练习技术面试：先回答自己的情况，再查看参考答案，最后明确点击继续。题库来自已有本地学习资料，保留来源、答案性质和许可信息。

- 在线试玩：https://lst016.github.io/interview-galgame/
- 分类、题库集合与关键词筛选，全量答案按分类分片加载。
- 输入回答、口头作答、参考答案与真实经历模板。
- 浏览器本地保存草稿、学习状态和续学位置，不发送个人回答到服务器。
- 无需 API Key；不调用模型，不自动评分。

## 收录范围

合并去重后共 4,759 道有题干的题目与 158 条牛客来源索引，分为 9 类、27 个集合；4,677 条提供本地参考答案，其余明确标注缺答或外链。旧版独有的 226 题保留在归档集合。清点覆盖 15 个直接输入文件及统一题库已有的上游来源，不把重复版本相加为新题。

## 本地运行

```sh
npm ci
npm run dev
```

验证和构建：

```sh
npm test
npm run build
npm run preview
```

## 数据更新

本仓库提交已清理的题库数据。导入脚本用于从原始学习目录重新生成数据，不要求线上构建访问个人电脑。输入清点、去重和外链规则见 DATA-SOURCES.md；发布前检查见 AUDIT.md。

不提交个人简历、实际面试逐字记录、浏览器回答草稿或密钥。参考答案、教学场景与伪代码不代表使用者的实际经历。未获明确分发许可的第三方答案只保留来源链接；不会用空白占位假称已经补答。

## 部署

GitHub Actions 在 main 更新后验证、构建并部署到 GitHub Pages。站点完全静态，适合 GitHub Pages；若以后增加 AI 评分，需要独立后端，不应把服务密钥放进前端。

## 许可与来源

项目代码采用 MIT；题库数据保留每项原有来源和许可，不能统一视为 MIT。详见 DATA-SOURCES.md。场景与角色 SVG 为本项目本地试玩制作的原创示意素材。
